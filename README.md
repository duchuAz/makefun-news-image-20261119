# makefun-news-image-20261119

Entry for make.fun's news-image competition: a front page summing up the world news of Thursday, 19 November 2026 in one 1024x1024 image.

`main.ts` (Node 22, standard library only) copies `entry.png` from the repository root to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`), creating the output directory if needed.
